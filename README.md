# 🎮 CodeDuel – Learning Game

CodeDuel là game học lập trình dành cho người mới bắt đầu,
tập trung vào Python và C++.

## 🎯 Mục tiêu

Giúp người học:
- Làm quen với lập trình
- Học Python
- Học C++
- So sánh Python và C++
- Luyện tập thông qua game

## 📚 Nội dung

### Python
- Biến
- if / else
- for
- while
- list
- function
- break
- continue

### C++
- Biến
- if / else
- for
- while
- array
- function

- ...
